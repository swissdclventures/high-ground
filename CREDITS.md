# Credits and asset licenses

The code in this repository is released under the MIT License — see [`LICENSE`](LICENSE).

This file covers the **assets** that ship with the scene: where they came from,
and what each one is licensed under. Every third-party asset here is used under
a license that permits redistribution in this repository and use in the
deployed World.

## Music

`sounds/punch/music/breaktime-sting.mp3`
`sounds/punch/music/deadly-roulette-sting.mp3`

> "Breaktime" and "Deadly Roulette" by Kevin MacLeod ([incompetech.com](https://incompetech.com))
> Licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/)

The scene ships short excerpts, not the full tracks. The punch machine fires a
melody once, as a celebration when a streak climbs a rung, so a two-minute track
was both wrong for the moment and dead weight in every bundle. Each excerpt ends
on a fade so the melody finishes rather than being cut.

## Voice and sound effects

`sounds/punch/voice-bad/`, `sounds/punch/voice-good/`, `sounds/punch/voice-top/`,
`sounds/punch/god-voice-*.mp3` — spectator and announcer lines, generated with
ElevenLabs for this project from scripts written for High Ground.

The remaining sound effects (impacts, machine rattle, charge rise, crowd beds,
tallies and turn cues) were produced for this project.

## 3D models and textures

All `.glb` models and their textures under `models/` and `images/` — the punch
machine and its cabinet, the sky island, the buildings, the trees, the garden
vegetation, the vehicles and the arena pieces — were authored for this project
in Blender and by the Swissverse building toolchain.

## Fonts and UI

The in-world UI is drawn with the Decentraland SDK 7 UI system and its built-in
font. No third-party font files ship in this repository.
